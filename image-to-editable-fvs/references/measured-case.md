## 2026-11-24 精修：坐标对齐 + 三个隐藏坑

之前 0.869 那版图表区是**空的**（没发现），根因和修复：
1. **坐标全错**：擦除区和图表位置来自 0.41 的 HTML 还原稿，跟原图图表差 60-200px。用 chart-coords.json 量原图真实坐标重做。
2. **图表成孤儿**：原生图表 `parent` 指向 d-group，合并删 group 后不渲染 → 合并时清空 parent。
3. **数据集被破坏**：writeXML 往返破坏 RowData 私有编码 → 保留 TableDataMap 原文。
4. **缩放裁字**：缩放图表 widget 后数字显示成 "65..." → 只平移不缩放。
修复后：0.873，7 图表完整可读、数据可改。坐标表见 global-business/chart-coords.json。
