# 大屏设计任务书（设计师 → Agent → HTML）

## 谁用、解决什么

**设计师**：想把脑子里的"数据大屏"变成能看、能改、能切图的 HTML 原型，但不知道该怎么跟 AI 说清楚。
**Agent**：接到"做个大屏"就要动手写代码，但没有画布尺寸、没有数据、没有模块划分，最后做出来的东西结构混乱、切不出图。

这个技能给一份**填空即用**的任务书模板 + 一套默认设计规范 + 7 条"为了以后能切图"的硬约束。

> 关键认知：大屏能不能顺利交付，**70% 在 HTML 写出来之前就决定了**。等做完了再想切图，往往要返工重写。

```
本技能（任务书）→ Agent 写 HTML → html-screen-to-design-source（切图/设计源）→ Figma/蓝湖 → 开发
```

---

## 第 1 步：先定 5 个参数（5 分钟，问清楚再开工）

| # | 参数 | 说明 | 例子 |
| --- | --- | --- | --- |
| 1 | **画布尺寸** | 固定像素，不做响应式 | `2752×1204`、`1920×1080`、`3840×1080`（超宽屏） |
| 2 | **模块划分** | 3~7 块，给每块一个名字和主题 | 页头 / 牧业 / 工厂 / 销售端 / 物流 / 电商 |
| 3 | **每块的数据** | 指标名 + 数值 + 单位；没有真数据就写"占位数据，可随机但需固定种子" | 自有牧场 4 座、日均产奶 520 吨 |
| 4 | **品牌与配色** | 主色、辅色、背景色（可直接给色值） | 深蓝底 `#020A18`、青 `#74DCFF`、金 `#F3D77D` |
| 5 | **气质** | 科技感 / 政务稳重 / 工业硬朗 / 消费品牌轻快 | 科技感，克制发光，不要满屏光污染 |

缺哪项就用括号里的默认值顶上，并在任务书里写明"这是我替你定的，可改"。

## 第 2 步：任务书模板（复制改括号即可）

```
【任务】按下面的规范做一块 XX（业务）数据大屏，输出可运行的单页 HTML。

一、画布
- 固定画布 2752×1204（= 688×301 @4x），`transform: scale()` 适配窗口，不做响应式断点
- 层叠顺序：页面底 → 模块底 → 卡片底 → 照片/图表 → 图标 → 文字

二、结构
- 页头：大标题 + 副标题 + 品牌 LOGO + 标语 + 3 个顶部指标（每组含图标、名称、2 个数值）
- 左列上：模块 A（标题 + 实景图 + 4 个指标条 + 1 图表 + 1 仪表盘）
- 左列下：模块 B（同上，无图）
- 中间：主视觉（地图/沙盘）+ 4 个 KPI + 3 张浮层卡（AI 预测 / 选址 / 实时动态）
- 右列上：模块 C（4 指标 + 2 图表）
- 右列下：模块 D（4 指标 + 3 图表）

三、数据（占位，必须固定，刷新后不变）
- 模块 A：自有牧场 4 座 / 奶牛存栏 31,882 头 / 日均产奶 519 吨 / 优质乳率 99.6%
- ……（逐块列全；图表给 7 个数据点）

四、视觉规范
- 底色 #020A18，卡片 #041A38→#062A4F 渐变，描边 rgba(47,155,214,.25)
- 主文字 #EDF8FF，次要 #9ECBE3，强调金 #F2E9B8，警示/增长 #49E38C
- 字体：SimHei / Noto Sans SC（不要用微软雅黑、PingFang 等非自由字体）
- 圆角切角 ≤10px，外发光克制（1px 描边 + 极轻 shadow），禁止大面积模糊光斑

五、图表
- 用 ECharts，7 点折线/柱状 + 2 个环形/仪表
- 坐标轴字号 9~11px，网格线 rgba(120,180,220,.12)，图例在标题右侧

六、工程要求（**这一节别删，决定后面能不能切图**）
- 见下方「第 3 步：7 条硬约束」

七、交付
- `index.html` + `css/` + `js/` + `assets/`，本地双击可开
- 附一张 2752×1204 的整页预览 PNG
```

## 第 3 步：7 条硬约束（为了以后能切图，必须写进任务书）

| # | 约束 | 不这么做会怎样 |
| --- | --- | --- |
| 1 | **文字必须是真文本**：标题、数值、图例、坐标轴、表格都用 DOM 文本，不许把文字画进背景图 | 切图后文字动不了、改不了一个字，规格也没法标注 |
| 2 | **层要分离**：卡片底（底色+边框+切角+发光）一张图，图标各自一张图，照片一张图，文字是文本 | 卡片和内容糊成一张，谁也没法单独下载或替换 |
| 3 | **图标用独立元素**：`<img>` 或 `background-image` 或内联 `<svg>`，一个图标一个节点；不要用字体图标（icon font） | 字体图标是字体，既切不出图也测不到位置 |
| 4 | **禁用设计工具不认的特性**：CSS 渐变文字（`background-clip:text`）、`backdrop-filter`、`mask`、复杂 `filter` | Figma 导入后：文字变黑、磨砂变实心、图层直接消失 |
| 5 | **固定画布 + 静态模式**：给一个开关（如 `?live=1`）默认关掉定时刷新/动画/随机数据 | 每次渲染都不一样，无法量坐标、无法逐像素验收 |
| 6 | **稳定命名**：每个元件给 `data-el="card__kpi"`、`data-el="icon__top-cow"` 这类固定名，重复元件加序号 | 切图和标记只能靠"第几个 div"，一改就全错位 |
| 7 | **占位数据要固定**：随机数用固定种子，时间类文字固定成常量 | 同上：不可复现 = 不可验收 |

补充两条经验：

- 照片/实景图请**保留原始 PNG**，不要在 HTML 里再压成 JPG（后面要转 RGBA PNG 交付，JPG 会带白底）
- 卡片外的"发光"尽量用 1px 描边 + 极轻阴影表达；大范围 `radial-gradient` 光斑在切图时会变成多余色块

## 第 4 步：验收（设计师先自己过一遍，再交下游）

设计侧：

- [ ] 2752×1204 下单屏不滚动，缩放窗口不变形
- [ ] 5 个模块层次清楚：标题区 / 指标区 / 图表区不打架
- [ ] 数字有单位、单位和数字字号不同级（数值 > 单位）
- [ ] 同类元素（4 个指标卡）间距、字号、颜色完全一致
- [ ] 发光克制：截图缩到 30% 还能看清结构

工程侧（决定能不能切图）：

- [ ] 每块文字都是 DOM 文本（选中能复制）
- [ ] 每个图标是独立节点（DevTools 里能单独定位）
- [ ] 卡片底与内容分层（隐藏文字后只剩底框）
- [ ] 没有 `background-clip:text` / `backdrop-filter` / `mask`
- [ ] 有静态模式，连渲染两次截图一致
- [ ] 元件都有 `data-el` 命名

---

## 第 5 步：怎么"改"（迭代话术）

大屏几乎不可能一次到位。用**定位 + 现象 + 期望**三句话描述，比"这里不好看"有效十倍：

> 「销售端模块」的 4 个 KPI 卡：数字和"万元"贴太近了，数字 26px、单位 12.5px，中间留 4px；卡片高度从 80 加到 84。
>
> 页头三个指标卡之间的分隔线看不见了，应该是 1px 竖向渐变线 + 6px 柔光。
>
> 地图区域偏小，底图裁到 751×446，标注文字 9px。# 供参考

反例（会得到随机结果）：「整体再高级一点」「颜色再好看点」。

---

## 第 6 步：交给下游

HTML 定稿后，直接进 `html-screen-to-design-source`：

> 用 **html-screen-to-design-source** 处理这个稿：HTML 在 `<path>`，素材在 `<path>`，画布 `2752×1204`。

它会做静态化 → 量几何 → 按类型切图 → 合成 SVG → 像素验收 → Figma/蓝湖兼容检查，
最后给出"强差异 / 文件体积 / 导出层数 / 素材命中率"四个数。

## 附：常见需求 → 参数速查

| 业务 | 常见模块 | 主视觉 | 备注 |
| --- | --- | --- | --- |
| 工厂/制造 | 产能、设备 OEE、质量、能耗 | 车间实景 + 产线示意 | 数值多用金色，单位小一号 |
| 零售/连锁 | 门店、会员、订单、渠道 | 全国地图 + 门店点位 | 地图建议拆底图/流向/点位三层 |
| 物流/冷链 | 仓、车、时效、温控 | 配送网络图 | 流向线单独一层，便于替换 |
| 农业/食品 | 牧场、产量、品质 | 实景航拍 | 实景图控制亮度，避免压过数据 |
| 政务/园区 | 人口、事件、告警 | 园区 3D 或平面图 | 配色稳重，少发光 |
