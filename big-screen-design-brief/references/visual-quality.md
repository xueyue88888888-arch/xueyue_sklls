# 大屏好看的具体做法

大屏 90% 的"不好看"，不是缺素材，是**层级没定、字号太杂、发光滥用、间距没节奏**。
下面每条都给了可执行的数字，不要靠感觉。

---

## 0. 先看骨架，再补皮肤

把参考图**缩到 25% 并去色**，只看明暗块：

- 能看出"几块、谁大谁小、留白在哪" → 骨架健康
- 缩完一片糊 → 骨架就有问题，别急着加发光和图标

复刻顺序永远是：**区块位置/占比 → 留白节奏 → 描边与层级 → 图标与发光**。
倒过来做（先堆特效）一定返工。

---

## 1. 一处焦点

一屏只允许一个视觉焦点（通常是主视觉：地图 / 沙盘 / 实景通栏）。
其余模块的装饰强度必须低于它 —— 具体做法：焦点区外的发光 ≤ 1px 描边 + 6px 柔光，焦点区可到 10px。

**自检**：眯眼看 3 秒，视线第一落点是同一个地方吗？不是就有两个焦点，删一个。

---

## 2. 深色底的深度靠明度，不靠阴影

| 层 | 建议值 | 相邻层亮度差 |
| --- | --- | --- |
| 页面底 | `#0A1220` ~ `#020A18` | — |
| 模块底 | 比页面底亮 3–5 | — |
| 卡片底 | 比模块底亮 4–6 | 用 100–135° 渐变（左上亮、右下暗）|
| 悬停/强调 | 比卡片底再亮 4 | 只用于可交互或高亮项 |

- 卡片边界：`1px solid rgba(47,155,214,.25)` + 极轻内发光 `inset 0 0 18px rgba(30,130,200,.2)`
- **不要**大范围 `box-shadow`（深色底上的黑影看不见，只会变脏）
- 卡片圆角/切角 ≤ 10px；同一屏只用一种切角语言

---

## 3. 发光纪律（最容易做土的地方）

- 全屏发光只允许 **3 类**：主标题、关键数值、地图/主视觉
- 1px 线 + 6–10px 柔光；**禁止**大面积 `radial-gradient` 光斑压在数据后面
- 发光不承担层级功能 —— 层级用明度差，发光只做"能量感"
- 金色数字 + 描边 + 发光三件套叠在一个数上 = 典型案例，选一样

**自检**：截图转灰度，如果还有地方"发白成了一团"，就是过曝了。

---

## 4. 字号阶梯（观看距离 2–5 米）

一屏字号种类 **≤ 6 种**，步进不要超过 ×1.25：

| 角色 | 字号 | 备注 |
| --- | --- | --- |
| 主标题 | 42–46 | 700，字距 -1.5 |
| 模块标题 | 26–28 | 700，配 15.5 副标题 |
| 关键数值 | 26–28 | 金色，tabular-nums |
| 卡片标题 | 15.5 | 500–600 |
| 正文/标签 | 12–13.5 | 400 |
| 单位/脚注 | 9–10.5 | 400，比数值小 2–2.5× |

- 数值比标签大 **≥ 1.6×**；单位是数值的 **0.5×** 左右
- 数字用 `font-variant-numeric: tabular-nums`（否则跳动时列不对齐）
- 数字右对齐、单位左对齐，中间 4px
- 深色底上次级文字**不用纯灰**，用主色提亮（如 `rgba(158,203,227,.9)`）

**自检**：把所有字号列出来数一遍，超过 6 种就合并。

---

## 5. 间距节奏

- 模块间距 = 卡片间距 × 2（例：卡片间 12 → 模块间 24）
- 卡片内 padding 统一 12–16，不要 8 和 20 混用
- 模块标题区高度统一（48–56），标题 → 内容的间距 > 内容 → 内容的间距
- 4 联指标条：每格等宽，分隔线 1px，指标名与数值左对齐同一条基线
- 图表卡：标题 15.5，图例在标题右侧同一行，图表区顶部留 1–2px

**自检**：把同类的 4 个卡片截图叠在一起，边界对不齐就是间距没统一。

---

## 6. 色彩克制

- 一个主色（青蓝）+ 一个强调色（金）+ 语义色（涨绿 / 跌红 / 告警橙）
- 同屏色相 **≤ 4**；强调色面积 **≤ 10%**
- 语义色只给涨跌和告警，不要拿来做装饰
- 对比度：正文 ≥ 4.5:1，大字 ≥ 3:1（深色底上最容易忽略）
- 图表系列色取主色系的 3–5 个明度档，不要彩虹

---

## 7. 图表语法统一

- 无边框、无背景；网格线 `rgba(120,180,220,.10)`，只留水平线
- 轴文字 9–11px，颜色比正文暗一档；不画轴线只留刻度
- 系列 ≤ 5；柱宽统一（同一卡片内）；折线 2px
- 图例在标题右侧、单行；去掉图例的小方块阴影
- 仪表盘：值在圆心，单位在值右下；环宽 ≤ 8
- 地图：底图压暗，点位 ≤ 3 种尺寸（普通/重点/枢纽），流向线 1px + 端点圆点

**自检**：把所有图表缩成 80px 宽，如果分不清谁是谁，说明样式太重。

---

## 8. 照片处理

```css
.photo img { filter: brightness(.88) saturate(1.02) contrast(1.02); }
```

- 压暗到比卡片底亮 10–20 即可，**永远不要比数据还抢眼**
- 通栏图四边渐隐（融进底色），不要硬边
- 照片里不要出现文字/水印/LOGO（AI 生成时用负面词排除）

---

## 9. 动效只留 2–3 处

- 数字滚动、地图涟漪、列表新增 —— 三选二就够
- 周期 2–4s，缓动 ease-out；其余全部静止
- 扫描线、旋转雷达、呼吸灯这类，除非客户明确要"监控感"，否则不加

**自检**：关掉所有动效，画面还能看懂吗？能，才说明动效是加分不是拐杖。

---

## 10. 大屏特有的反模式

| 反模式 | 为什么土 | 怎么改 |
| --- | --- | --- |
| 满屏发光 | 没有层级，全是噪音 | 只留 3 类发光 |
| 金色 + 描边 + 发光三件套 | 过曝，数字看不清 | 选一样 |
| 7 种以上字号 | 没有层级 | 合并到 ≤ 6 |
| 卡片套卡片套卡片 | 结构不清 | 最多两层容器 |
| 彩虹图表 | 无信息增量 | 主色系 3–5 档 |
| 每个模块边框都不一样 | 像拼的 | 统一一种切角+描边语言 |
| 装饰性扫描线/雷达乱飞 | 抢注意力 | 删 |
| 渐变文字 | 设计工具不认，且廉价 | 实色 + 字重 |
| 标题上方小英文（eyebrow） | 无信息量 | 删，让标题自己说话 |

---

## 11. 交付前自评（每项 0–2 分，≥ 16 才交付）

| # | 检查项 | 判据 |
| --- | --- | --- |
| 1 | 单一焦点 | 眯眼 3 秒落点一致 |
| 2 | 三层明度 | 页面/模块/卡片亮度差 3–6，肉眼能分层 |
| 3 | 发光纪律 | 发光 ≤ 3 类，灰度截图无过曝团块 |
| 4 | 字号阶梯 | ≤ 6 种，数值/单位比例 ≥ 1.6 / 0.5 |
| 5 | 间距节奏 | 模块间距 = 卡片间距 × 2，同类卡边界对齐 |
| 6 | 色彩克制 | 色相 ≤ 4，强调色面积 ≤ 10% |
| 7 | 图表统一 | 无边框、网格 10% 透明、图例单行 |
| 8 | 照片不抢戏 | 压暗后亮度 ≤ 卡片底 +20 |
| 9 | 动效克制 | ≤ 3 处，关掉后信息仍完整 |
| 10 | 缩略可读 | 缩到 30% 仍能分辨模块与主次 |

低于 16 分不要交 —— 客户看到的第一个问题一定是这几项里的。

## 参考

这份清单融合了通用前端设计规范（对比度、间距、字号阶梯、动效克制）与大屏垂类经验（发光纪律、三层明度、图表语法）。
