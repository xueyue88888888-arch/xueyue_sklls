# AI 图片素材：Prompt 模板与一致性清单

C 类素材（照片级场景）用 `image-gen` 技能生成。这块最容易翻车的地方不是"画得不好"，
而是**五张图放一起不像一套**：色温不一致、光源方向相反、透视不同、分辨率不齐。

---

## 1. 生成顺序（照这个顺序，返工最少）

1. **先占位**：HTML 里先放同尺寸纯色块或模糊渐层，把布局和层叠定死
2. **再定基准图**：先出 1 张最"定调"的图（通常是最大幅、最显眼的那张，比如门店夜景通栏）
3. **锁定风格词**：把基准图用的风格描述抽出来，后面每张都带上
4. **批量出图**：按模块顺序出，每张出 2–3 个候选挑 1 张
5. **统一后处理**：一起过一遍亮度/饱和/裁切，再替换占位

---

## 2. Prompt 公式

```
[主体] + [场景] + [光线] + [镜头/景深] + [色调] + [用途约束] + [负面词]
```

| 段落 | 写什么 | 例子 |
| --- | --- | --- |
| 主体 | 画面里最主要的物 | 黑白花奶牛成群、乳品瓶与玻璃杯 |
| 场景 | 在哪里、周围有什么 | 清晨高原牧场、深色大理石台面 |
| 光线 | 方向 + 软硬 + 色温 | 侧逆光柔和、冷调环境光 |
| 镜头 | 焦段 + 机位 + 景深 | 35mm 俯拍、浅景深特写 |
| 色调 | 与整屏统一的色系 | 冷蓝绿调，暗部偏深蓝 |
| 用途约束 | 尺寸、留白、要融进深色底 | 宽幅 2.5:1，右侧留空给数据卡，四边可渐隐 |
| 负面词 | 固定一串 | text, watermark, UI, logo, border, frame |

---

## 3. 模板库（按大屏常见素材）

**顶部通栏 / 城市夜色天际线**
> 深夜城市天际线航拍，玻璃幕墙楼宇灯火零星，冷蓝色调，远处雾气朦胧，宽幅超广角，
> 上沿留出标题空间，下沿渐隐入深蓝，无文字无水印

**牧场 / 农田航拍**
> 清晨高原牧场航拍，绿色草场与黑白花奶牛成排，侧逆光柔和，35mm 宽幅俯拍，
> 冷蓝绿调与深蓝夜色统一，画面右侧留空，无文字无水印

**工厂 / 车间**
> 现代化乳品工厂车间航拍，不锈钢产线整齐排列，顶部冷白光均匀，50mm 微俯，
> 工业冷蓝色调，画面下方留空给数据，无文字无水印

**物流 / 冷链运输**
> 冷链卡车行驶在城市高架，黄昏逆光，车灯轨迹轻微拖影，35mm 跟拍侧视角，
> 冷蓝与暖橙对比，画面右侧留空，无文字无水印

**产品摆拍（食品/乳品）**
> 深色大理石台面上，乳品瓶、玻璃杯、鲜果静物陈列，柔和顶光 + 边缘轮廓光，
> 85mm 浅景深特写，冷调高光，背景为深蓝渐变可抠像，无文字无水印

**门店 / 场景**
> 夜晚街边的现代乳品门店，暖色内光透过玻璃，人流虚化，35mm 平视，
> 冷蓝环境与暖黄内光对比，画面右侧留空，无文字无水印

**地图 / 抽象数据底纹**（当 D 类不方便用 ECharts 时）
> 深蓝色抽象地图等高线纹理，细线网络节点，微弱发光，扁平矢量感，可无缝平铺，
> 无文字无水印

## 4. 一致性清单（生成完逐条对）

- [ ] 所有图的光源方向一致（都从左上/右上，不要一半左一半右）
- [ ] 色温一致：冷调就全冷调，不要一张暖橙一张惨白
- [ ] 暗部色相接近（都偏深蓝，不要一张偏紫一张偏灰）
- [ ] 透视/机位接近（不要一张超广角一张长焦压缩）
- [ ] 分辨率 ≥ 设计稿显示尺寸（最好 2 倍），宽高比与显示框一致
- [ ] 无文字、无水印、无 UI 元素、无品牌 LOGO
- [ ] 主体没有顶到画布边缘（要给标题/数据卡留出呼吸区）
- [ ] 文件命名能看出用途：`photo__pasture.png`、`photo__storefront.png`

## 5. 后处理（统一这三步）

```css
/* 大屏里照片永远不该比数据抢眼 */
.photo img { filter: brightness(.90) saturate(1.02) contrast(1.02); }
```

1. **压暗**：`brightness(.85–.92)`，视底图亮度调
2. **降饱和**：`saturate(.95–1.05)`，避免照片比数据卡更艳
3. **边缘渐隐**：通栏图上下/左右用 `mask-image` 或渐变色块过渡到页面底色
   （注意：渐隐如果必须在 Figma 里还原，就要烘进 PNG，别留 `mask`）

## 6. 抠像 / 透明底

需要透明背景时（图标化照片、悬浮产品）：

1. 先出**纯色背景**版本（`纯白背景` 或 `纯黑背景`，别让模型自己发挥）
2. 用抠图工具去掉背景 → 导出 RGBA PNG
3. 检查四条边：不透明纯白/纯黑环 = 没抠干净，重做
4. 交付时统一 RGBA PNG（JPG/RGB 会被设计工具铺白底）

## 7. 归档

每张图在 `assets/` 里配一条记录（可写进 `assets/README.md`）：

| 文件 | 用途 | 显示尺寸 | 生成 prompt 摘要 | 后处理 |
| --- | --- | --- | --- | --- |
| `photo__pasture.png` | 牧业模块通栏 | 717×285 | 清晨高原牧场航拍… | ×0.9 / 右侧渐隐 |
| `photo__storefront.png` | 销售端通栏 | 1236×552 | 夜晚门店暖光… | ×0.96 / 四边渐隐 |

**为什么要记 prompt**：三个月后要换一张同风格图、或者要出 4K 版本，没有 prompt 就得从零重猜。
